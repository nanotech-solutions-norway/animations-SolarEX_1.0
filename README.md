# SolarEX mounted panel assembly animation

Fresh GitHub Pages deployment for the mounted-panel-assembly live demo.

## Scope

- Static GitHub Pages implementation.
- Dedicated route: `/mounted-panel-assembly/`.
- Procedural Three.js model; no external image assets required.
- Wireframe / x-ray technical SolarEX visual style.
- 3 × 3 red highlighted solar-cell block.
- Central pedestal stand, base plate, rear rails, junction box, cable routing and frame details.
- Reduced-motion fallback.

## Governance

This deployment intentionally replaces the previous `gh-pages` tree with a minimal clean site: root redirect, `.nojekyll`, this README, and the dedicated mounted panel assembly demo.
